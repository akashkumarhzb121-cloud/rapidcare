# RapidCare Backend API

A production-ready REST API for AI-powered ambulance dispatch and hospital bed management.

## Features

- JWT-based authentication with role-based access control
- Google Gemini API integration for medical triage assessment
- Real-time updates via Socket.IO
- Hospital bed availability management
- Distance-based hospital matching using Haversine formula
- MongoDB with Mongoose ODM

## Prerequisites

- Node.js (v14 or higher)
- MongoDB (local or Atlas)
- Google Gemini API key
