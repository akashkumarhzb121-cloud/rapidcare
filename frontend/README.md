# RapidCare Frontend

A React-based frontend for the RapidCare ambulance dispatch system.

## Features

- Role-based dashboards (Operator & Hospital Staff)
- Real-time updates via Socket.IO
- AI-powered incident creation with Gemini API integration
- Hospital bed availability management
- Responsive design with Tailwind CSS

## Prerequisites

- Node.js (v14 or higher)
- Backend API running (see backend README)
